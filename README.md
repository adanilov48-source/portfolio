# Портфолио: Александр, веб-дизайнер

Личный сайт-портфолио: сайты, дизайн мобильных приложений, графические постеры.

## Что внутри
- `index.html` — главная страница (стили внутри файла)
- `.gitignore` — список файлов, которые не попадут на GitHub

## Как открыть локально
Дважды кликни по `index.html`, откроется в браузере.

## Как опубликовать (GitHub Pages)
Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)` → Save.

## Что заменить
- Имя, описание и контакты
- Три блока в разделе «Работы» на свои проекты
